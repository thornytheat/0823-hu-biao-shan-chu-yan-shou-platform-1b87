# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 跨分区换版时，在“试点分区”填写启用同序列等值剔除规则的分区；其他分区保持旧规则，不要整批换版或拆批重报。
3. 执行批次后，在业务阶段定位异常分组、分区计数和原始记录键。面板会直接显示“可签发”或“不可签发”及原因。
4. 修复来源文件，重新上传并执行。历史批次保留供复核。
5. 对账无差异、所有分区预期数一致、无坏行且所用规则仍 active 时可签发。对仍有差异的版本可填写暂缓意见；若规则在签发前被停用/换版，旧批次会得到 `STALE_RULE_VERSION`，需重算后再签。
6. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
