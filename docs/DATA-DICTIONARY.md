# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 data, position_delete, equality_delete, snapshot。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `file`、`partition`、`sequence`、`position`、`row_key` 排列。最终值单位见阶段结果。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

仅使用序列不大于快照的文件。等值删除匹配分区与业务键；旧规则要求删除序列严格大于数据序列，试点分区（由 `PILOT_PARTITIONS`、请求字段 `pilot_partitions` 或规则设置指定）启用同序列生效的新规则。位置删除精确匹配文件与行偏移，同序列可删除。指向已知文件不存在位置的删除进入待复核。

每个业务组可使用一个 `partition=0` 的全局快照，其 `position` 为预期可见总行数；也可为每个分区提供快照行，以该行的 `partition` 和 `position` 表达分区预期可见数。即使总行数恰好相等，任一分区计数不符也会阻止整批签发。清单会记录各分区实际值、预期值和所用规则版本；签发时会复核这些规则是否仍为 active。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。
